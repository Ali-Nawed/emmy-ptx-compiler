# Scalar tiles and subtraction

The extended tests found that Emmy represents one-element work as Tile(axes=()),
whose n_elements property is 1. compile.py used to reject an empty axis tuple
alongside auxiliary/rasterized schedules. It now accepts it and uses the existing
global-worker bounds guard so only worker zero executes. There are no axis
variables to decode; the emitted body uses the indices already provided by Emmy.

The arithmetic dispatcher now maps subtract to sub.rn.f32. Operands keep their
IR order: result = first argument - second argument.

Validation:

- All 16 fresh Emmy-generated f32 cases pass on the competition RTX 5090: eight
  operations at sizes 1 and 129 (row sums use three rows).
- All eight official MVP problems still pass on the same runner.
- The full 80-case matrix reports 16 passes and 64 compiler rejections for
  non-f32 datatypes. Rejected cases were not uploaded.
- Local tests compile and assemble the 16 f32 fixtures, and verify the NumPy
  references and typed result checker.

The extended report is tests/extended/results.json. Official MVP results are
review/mvp-scalar-subtraction-results.json. Only PTX generated by our own
compile.py was uploaded. This change does not establish hidden-set coverage.
