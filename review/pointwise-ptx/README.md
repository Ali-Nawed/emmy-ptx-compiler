# Pointwise PTX review

Snapshot generated by our own compile.py on October 22, 2026. No nvcc or reference CUDA was used to generate these files. All four pointwise problems passed the public runner with exact results using this compiler version.

| File | Computation | Input length | Launch | Logical workers |
|---|---|---:|---|---:|
| p00_scalar_add.ptx | x0 + x1 | 128 | 1 block, 256 threads | 64 |
| p01_vector_add.ptx | x0 + x1 | 1024 | 2 blocks, 256 threads each | 512 |
| p02_scale_shift.ptx | x * 2 + 1 | 4096 | 4 blocks, 256 threads each | 1024 |
| p03_relu_mul.ptx | relu(x) * y | 2048 | 2 blocks, 256 threads each | 512 |

The entry name is shared by some files, so each problem has its own PTX module. Buffer parameters follow the matching problem's meta.json arg_order.

Read each file from top to bottom: parameters, register declarations, parameter loads, global worker index, tile bounds guard, loads/arithmetic/stores, return. Arithmetic on indices uses element offsets; mul.wide.s32 scales them by four to get byte offsets for f32.

Regenerate one file from the repository root in Ubuntu:

```bash
.venv/bin/python compile.py problems/p00_scalar_add/k_add_pointwise.ir.json > review/pointwise-ptx/p00_scalar_add.ptx
```

These are snapshots: rerun the compiler after changing it to refresh the files. No new runner tests or submissions were made when saving this review folder.
